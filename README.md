Расширенный пул завершён **6 ноября 2026 года в 21:28 UTC** на GPU 0: **504 обучения, 21 000 эпох, 504 test-оценки, 168 измерений динамики ранга и 2520 серий измерения инференса**. Исследованы ResNet-20 и Mini-ViT на CIFAR-10 / CIFAR-100, три seed, сокращение FLOPs на 10%, 25% и 40%. ERank сравнивается с Uniform, Random-width, L1, Network Slimming, Taylor, HRank и SVD; адаптации методов для ViT описаны в протоколе.

В 24 заранее заданных сравнениях статистически подтверждённого преимущества ERank над Uniform не обнаружено. Это не доказывает эквивалентность методов: использованы только три seed. Дополнительные сравнения со всеми бейзлайнами — описательные. Таблицы показывают параметры, FLOPs, качество и loss относительно исходной модели (100%), а изменение скорости — относительно её времени инференса.

Репозиторий: [lm-cyber/efficient_rank](https://github.com/lm-cyber/efficient_rank).

## Что включено

Код двух пулов, исходный ноутбук, протоколы, конфигурации, индексы разбиений, архитектуры, журналы эпох, test-предсказания, измерения времени, динамика ранга, итоговые CSV, отчёты и графики. Снимки кода сохраняют историю реализации. Датасеты, checkpoint и крупные кеши активаций исключены из Git; они создаются при запуске экспериментов. Исторические протоколы и снимки могут содержать действовавшую при их создании пометку об отложенной публикации.

## Воспроизведение

Использовались Python 3.12, PyTorch 2.5.1 + CUDA 12.1 и NVIDIA A100 80 GB. Точное окружение: [environment.json](runs/erank_models_v2/environment.json).

```bash
git clone https://github.com/lm-cyber/efficient_rank.git
cd efficient_rank
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r experiments_v2/requirements.txt
```

Для пересборки читаемых отчётов из опубликованных измерений GPU и checkpoint не нужны:

```bash
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 python3 experiments_v2/readable_report.py
```

Полный запуск на GPU 0, включая подготовку данных и повторное обучение: [инструкция](experiments_v2/README.md#execution). Перед ним нужно перенести опубликованные результаты в отдельную папку, как показано в инструкции: маркеры завершённых обучений включены в Git, а соответствующие веса — нет.
