# Артефакты расширенного пула

- [Краткие результаты в процентах](findings.md).
- [Полный отчёт: качество, ресурсы, скорость и архитектуры](report.md).
- [ERank против всех бейзлайнов](erank_vs_baselines.md).
- [Итоговый статус выполнения](progress.md): все этапы завершены.
- [Действующий протокол](protocol_current.md): постановка и правила анализа с зарегистрированными уточнениями.
- `protocol.md`: исходная копия протокола при запуске; сохранена как история, без перезаписи.
- `protocol_amendments.json`: изменения протокола с временем и причиной. Размер калибровки Taylor/HRank выровнен до 1024 до их основных сравнений и до любых test-оценок.
- `analysis_protocol.json`: первичные статистические сравнения, зафиксированные до test.
- `planned_runs.csv`: полный список 504 обучений. `config.json` — действующие параметры.
- `models/`: отдельные архитектуры, журналы эпох, test-предсказания и завершённые оценки. Checkpoint сохранены локально и исключены из Git. Наличие `train_done.json` означает завершение исходного обучения; `test.json` появился отдельно после обучения всего пула.
- `source_base/`, `source_pool/`, `source_processes/`: снимки реально использовавшегося кода; история технических изменений — `implementation_notes.json`.
- `verification_*.json`: проверки численных операций, сжатия и эквивалентности вариантов исполнения.
- `environment.json`, `data_sha256.json`, `splits/`: окружение, контрольные суммы данных и точные индексы разбиений.

Все итоговые файлы созданы: `frozen_test_manifest.json`, `results.csv`, `report.md`, графики и исходные измерения в `latency/`.

Читаемые таблицы и графики используют процентные отношения. Исходные измерения в `results.csv` сохранены; `relative_metrics.csv` и `relative_summary.csv` содержат их относительное представление. Полные 168 описательных сравнений ERank с бейзлайнами: `erank_vs_baselines.csv`, отдельные парные значения по seed — `erank_vs_baselines_per_seed.csv`.

Определения и неизменившиеся контрольные суммы исходных данных: `relative_report_metadata.json`. Проверки формул и покрытия сравнений: `relative_report_validation.json`. Прежний вид отчёта с абсолютными единицами сохранён в `report_history/absolute_units/`.

Код и перечисленные результаты включены в [репозиторий](https://github.com/lm-cyber/efficient_rank). Датасеты, checkpoint и временные файлы остаются локально. Пометки об отложенной публикации в исторических протоколах отражают состояние на момент их создания. Инструкция для нового запуска без опубликованных весов: [experiments_v2/README.md](../../experiments_v2/README.md).
