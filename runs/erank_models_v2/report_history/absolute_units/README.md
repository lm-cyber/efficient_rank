# Артефакты расширенного пула

- [Текущий прогресс](progress.md): автоматически обновляется каждые 30 секунд.
- [Действующий протокол](protocol_current.md): постановка и правила анализа с зарегистрированными уточнениями.
- `protocol.md`: исходная копия протокола при запуске; сохранена как история, без перезаписи.
- `protocol_amendments.json`: изменения протокола с временем и причиной. Размер калибровки Taylor/HRank выровнен до 1024 до их основных сравнений и до любых test-оценок.
- `analysis_protocol.json`: первичные статистические сравнения, зафиксированные до test.
- `planned_runs.csv`: полный список 504 обучений. `config.json` — действующие параметры.
- `models/`: отдельные архитектуры, checkpoint, журналы эпох и завершённые оценки. Наличие `train_done.json` означает завершение обучения; `test.json` появляется отдельно после обучения всего пула.
- `source_base/`, `source_pool/`, `source_processes/`: снимки реально использовавшегося кода; история технических изменений — `implementation_notes.json`.
- `verification_*.json`: проверки численных операций, сжатия и эквивалентности вариантов исполнения.
- `environment.json`, `data_sha256.json`, `splits/`: окружение, контрольные суммы данных и точные индексы разбиений.

После завершения создаются `frozen_test_manifest.json`, `results.csv`, `report.md`, графики и исходные измерения в `latency/`. Отсутствие этих файлов во время обучения не означает нулевой результат.

Все данные остаются локально. Публикация отложена по указанию пользователя.
